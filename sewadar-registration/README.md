# Sewadar Registration

**Sewa Management · New feature · v1.4 · 22 Nov 2026 · Zonal IT Team**

## What is being added

A Nominal Roll picks its sewadars from the BMS (Badge Management System) database. In some States, BMS is not yet in use for day-to-day badge work, and their sewadar records, loaded into BMS once, cannot be refreshed. This feature adds a light **Sewadar Registration** screen under Sewa Management for those States, to register a Permanent Badge sewadar in BMS with only the details a Nominal Roll needs.
