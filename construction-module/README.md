# Construction Module — prototype v2.0

A clickable model of four proposed changes to the Construction Module, shared for review before development starts. All records in it are made up; nothing is saved.

Open: https://umesh-ls.github.io/prototypes/construction-module/

The one page holds three views, switched from the bar at the top:

| View | What it shows |
|---|---|
| Overview | What is new in this version and how to review it |
| Prototype | The full module, with a switch between the six roles |
| Clarification flow | Who asks, who answers and who closes a clarification |
